# trendradars_research

Исследование методологий оценки и ранжирования трендов (trend radars): сравнение подходов, восстановление формул скорринга и проверка их воспроизводимости.

## О проекте

Репозиторий содержит разбор существующих методологий построения тренд-радаров и оценки трендов: от консалтинговых и академических до коммерческих SaaS-продуктов. Для каждой методологии проанализированы:

* состав входных параметров и шкалы оценки;
* порядок этапов расчёта;
* формула свёртки итогового балла;
* возможности автоматического расчёта из открытых данных;
* воспроизводимость опубликованных чисел.

В репозитории также есть скрипт сборки исследовательского портала (`build_portal.py`), который сверяет восстановленные формулы с исходными данными и генерирует итоговый HTML с встроенными иллюстрациями.

## Методологии

| # | Методология | Происхождение | Что разобрано |
|---|-------------|---------------|---------------|
| 1 | Гравитационные тренды (SBS) | консалтинг | матрица 2×2, шкала {0,1,3,9}, 5 источников неопределённости |
| 2 | Trendradar (4strat) | продукт | 4 алгоритма свёртки, весы на «человек × объект × параметр» |
| 3 | TSI + ROESI (Trendtracker) | SaaS-вендор | ранговая таблица, радар, прогноз пика тренда |
| 4 | Trend Score + Opportunity Score / TIE (Trend Hunter) | консалтинг + медиа | формула `(Popularity + Activity + Freshness) / 3 / 10`, проверено на 95 из 95 |
| 5 | Emergence Score (Porter, Carley) | наукометрия | `EScore = 2 × Active Period Trend + ...`, валидация на будущем периоде |
| 6 | Слабые сигналы Yoon — KEM и KIM | академия форсайта | экспоненциальное затухание, топ-500 слов на интервал |
| 7 | BERTrend | RTE France (2024) | отсев после измерения, архитектура и интерфейс |
| 8 | Itonics Trend Radar | продукт | визуализация и управление трендами |
| 9 | HSE / iFORA | академия | форсайт и обнаружение слабых сигналов |

Подробный разбор каждой методологии — в папке [`methodologies/`](./methodologies).

## Основные результаты

* **Формула Trend Hunter восстановлена точно:** `Score = (Popularity + Activity + Freshness) / 3 / 10`, подтверждена на 95 из 95 наблюдений и на архивных копиях 2019–2023.
* **Проверка предсказательной силы есть только у одной методологии из семи** (EScore — отложенная проверка на 3 года).
* **Отсев слабых сигналов обычно стоит до расчёта балла** (SBS, 4strat, Yoon) — это исключает из изучения именно те сигналы, которые метод ищет. BERTrend — первая методология, где отсев происходит после измерения и обратим.
* **Не все формулы восстановимы из открытых источников:** у Trendtracker ROESI, у 4strat часть алгоритмов, у Yoon часть констант скопированы без обоснования.

## Как собрать портал

Требуется Python 3.

```bash
python3 build_portal.py
```

Скрипт:
1. Сверяет восстановленную формулу тепловой карты (SBS) и формулу Trend Hunter с исходными данными;
2. Встраивает все иллюстрации из `assets/` как data URI (для работы при строгой CSP);
3. Генерирует файл `portal.html`.

Если числа не сходятся, сборка останавливается с ошибкой.

## Данные

* `data/trendhunter_scores.csv` — выгрузка баллов Trend Hunter (popularity, activity, freshness, опубликованный score).
* `criteria.json` — набор оценочных критериев, используемых при разборе методологий.
* `summary.csv` / `summary.md` — сводная таблица по всем методологиям.
