### 2. Trendradar — платформа 4strat

- **URL:** рабочий инстанс https://my.trendradar.de/ · официальная справка https://help.foresight-cockpit.com/trendradar/ · маркетинг https://www.4strat.com/trendradar/
- **Разработчик:** 4strat GmbH, Берлин, основана в 2016; CEO Томас Колонко. Trendradar — облегчённая версия их платформы Foresight Strategy Cockpit (FSC)
- **Разобранная версия:** 3.9.1
- **Дата обращения:** 2026-08-08
- **Доступность:** справка открыта целиком без регистрации; сам продукт закрыт — разбор сделан под учётной записью в демонстрационном пространстве (7 трендов о мобильности, оценок не проставлено)
- **Карточка:** [methodologies/4strat-trendradar.md](methodologies/4strat-trendradar.md)
- **Иллюстрации:** 10 снимков интерфейса в `assets/` (`4strat_*.png`) + копии `web_4strat_*.png` для встраивания в портал. Экраны: оценка, настройка критериев (все три колонки заполнены), форма вычисляемого критерия (алгоритмы и собранная формула), проверочная таблица с посчитанным итогом, раскладка по STEEP, экран связей, радар, мониторинг, извлечённые сущности
- **Где лежит механика:** **не в документации.** Три сорта критериев (Group / Single / Calculated), четыре алгоритма свёртки и шесть функций консолидации найдены только в интерфейсе; в справке их нет вообще. Заметки о выпусках доведены до версии 3.4.0 при работающей 3.9.1
- **Что дала официальная справка:** правило детекции всплеска («average amount of results of the last 15 days»), оценка кластера («Trendclusters adopt the mean value of their assigned trends»), уточнение про вес оценщика (задаётся на связку «оценщик × тренд × критерий»), полная матрица совместимости типов шкал с каналами радара и портфолио, четыре типа шкал с их ограничениями
- **Замечание по методу поиска:** справку не нашли ни веб-поиском, ни перебором поддоменов `4strat.de` — она живёт на отдельном домене `help.foresight-cockpit.com` и обнаружилась только по ссылке «Learn more» изнутри самого продукта. **Вывод: для продуктов документацию искать из интерфейса, а не снаружи.**
- **Арифметическая проверка формулы: проведена экспериментом.** В поставке проверять было не на чем — ни одного вычисляемого критерия и ни одной готовой оценки. Поэтому в системе заведены единоличный критерий («Mentions per day (from Monitor)», поле ввода 0…100000) и вычисляемый («Priority score», алгоритм Weighting: Industry Impact ×3, Desirability ×2, Time Frame ×1), после чего оценён тренд про водород: 3 / 7 / 3. Система вернула **50,75757575757576**. Формула `ИТОГ = мин + (макс−мин) × Σ(вес · (значение−мин_кр)/(макс_кр−мин_кр)) / Σвес` даёт то же значение до последнего знака; альтернативы (простое среднее — 51,52; взвешенное среднее без приведения к шкалам — 3,67; сумма взвешенных долей — 3,05) отброшены. **Совпало 1 из 1**, чего для детерминированной формулы с периодической дробью достаточно
- **Что ещё выяснено экспериментом, а не чтением:** вычисляемых критериев может быть несколько, но **вложить один в другой нельзя** — в списке входов только неvычисляемые, поэтому свёртка строго одноярусная и иерархию показателей уровня SBS на платформе не собрать. Единоличный критерий **попадает** в список входов формулы, то есть измеренное число можно ввести руками и оно станет полноправным участником расчёта. Если хотя бы один вход формулы не заполнен, итог не считается вовсе — не нулём, а отсутствием. Внутреннее имя вычисляемого критерия в коде и API — `group`, поэтому поле `group: true/false` в ответах API означает «объединяет другие критерии», а не «групповая оценка»
- **Расшифровка STEEPMC у 4strat:** Society, Technology, Environment, Economy, Politics, **Military, Cyber**. Рамка раздвоена: на экране раскладки трендов из коробки только пять областей STEEP плюс «Not assigned» (свои добавляются), а полные семь букв живут в фильтрах поиска и мониторинга, где статьи размечаются автоматически
- **Порядок шагов Link и Organize:** продукт противоречит себе — тур говорит Scan → Organise → Link, боковое меню нумерует Scan → Link → Organize. Проверено по экранам: в Organize лежат **тренды** (не сигналы), кластер — это кластер трендов, тренды создаются и там и там, кластеры наполняются и там и там. По логике данных первичен Organize, но жёсткой зависимости нет — «восемь шагов» на деле не последовательность, а восемь рабочих мест

### 3. Trend Strength Index + ROESI — платформа Trendtracker

- **URL:** https://trendtracker.ai/ — сайт продукта. Разобрано локально 119 страниц: весь блог (≈100 статей), все разделы платформы и «данные, которые мы мониторим», страницы use cases

- **Дата обращения:** 2026-08-08
- **Доступность:** сайт и блог открыты целиком; сам продукт платный, доступ по демо. Метод объявлен проприетарным
- **Карточка:** [methodologies/trendtracker-tsi-roesi.md](methodologies/trendtracker-tsi-roesi.md)
- **Ключевые страницы механики:** `/blog-posts/trend-strength-index-vs-hype-a-data-driven-way-to-track-real-signals` (процедура расчёта TSI из 4 шагов), `/blog-posts/whats-rising-whats-fading-how-to-interpret-trend-velocity` (шкала Trend Change −3…+3, состав ROESI), `/blog-posts/how-to-build-a-trend-radar-a-step-by-step-guide-for-strategy-teams` (шесть этапов процедуры, определение TSI через скользящее среднее за 12 мес), `/blog-posts/what-is-a-strategic-intelligence-platform-a-guide-for-enterprise-teams` (11 типов индикаторов и «пять измерений» TSI)
- **PDF:** «Why use the ROESI model?» — https://25362507.fs1.hubspotusercontent-eu1.net/hubfs/25362507/Trendtracker_Why-use-the-ROESI-model_PDF.pdf. Одна страница, весь смысл — в картинке; текст извлекается, определения ступеней ROESI — только из изображения
- **Иллюстрации:** 11 содержательных в `assets/` (`tt_*.png`) + `web_tt_*.jpg` для портала. Механику несут четыре: таблица Trend Board со столбцами Strength/Change/Forecast/Horizon/Strategy, карточка Forecast со шкалами, карточка тренда в Discover, схема шести этапов
- **Арифметическая проверка:** проведена на единственном доступном примере — таблице Trend Board с тремя строками. **Правило ROESI не восстанавливается**: 0 из 3 правдоподобных гипотез (по силе, по прогнозу, по разности прогноз−сила). Подробности в карточке, раздел 2.6
- **Внешняя проверка:** искали научные публикации основателей, патенты, опубликованные пороги ROESI, независимые технические обзоры. Найден **один** содержательный внешний текст — блог инвестора Armilar Venture Partners, https://medium.com/armilar-venture-partners/why-armilar-invested-in-trendtracker-a96bb7f4b981 (прочитан по первоисточнику через reader-прокси, curl блокируется Cloudflare). Там единственное описание весов внутри TSI: позиция упоминания (заголовок vs тело), ранг источника, эволюция контекста
- **Финансирование:** €1.8 млн от Ageas и Capricorn Partners (2022–2023); Series A $7 млн / €5.9 млн, лид Armilar Venture Partners, декабрь 2025
- **Демо-доступ:** бесплатного тарифа и пробного периода нет. Страница тарифов https://trendtracker.ai/pricing — три пакета (Team, Program, корпоративный), цены за кнопкой «Get pricing», везде «Talk to an expert». Формально открыта самостоятельная регистрация по рабочей почте: https://app.trendtracker.ai/public/sign-up — не проверялась. Раздел https://trendtracker.ai/trend-radars существует, но карточки радаров подгружаются скриптом и без входа пусты («Report title · 0 Clusters · 0 Trends»)
- **Ключевое противоречие, найденное при доработке:** вендор в статье «What Trendtracker Doesn't Do» (май 2025) утверждает, что платформа «не ранжирует источники по предвзятости, авторитетности автора или наличию рецензирования, и это сделано намеренно»; инвестор в декабре 2025 пишет, что алгоритм «организует источники иерархически, приоритизируя источники с высоким уровнем сигнала» и учитывает позицию упоминания (заголовок vs тело). Одно из двух неверно
- **Замечание по методу разбора:** единого методологического документа у вендора нет — механика собирается из блога, снимков интерфейса и одного PDF. При этом определения TSI в разных статьях **противоречат друг другу** (пять версий), а объём корпуса назван четырьмя разными числами. Это не трудность чтения, а свойство самого источника, поэтому вынесено в слабые стороны карточки

### 4. Trend Score + Trend Intelligence Engine / Opportunity Score — Trend Hunter

- **URL:** https://www.trendhunter.com/trend-intelligence-engine — страница методологии («Our Methodology (TIE)» в меню). Также разобраны: шесть страниц паттернов `/pattern/{convergence,divergence,cyclicality,redirection,reduction,acceleration}`, `/megatrends`, `/about-trend-hunter`, `/editorial-standards`, `/about`, `/faq`, `/pro`, `/plans`, `/dashboard` и 95 карточек идей вида `/trends/<slug>`
- **Организация:** Trend Hunter Inc., Торонто. Основатель и CEO — Jeremy Gutsche, автор книг «Better and Faster» (2015) и «Create the Future» (2020)
- **Дата обращения:** 2026-08-09
- **Доступность:** сайт открыт целиком без регистрации, **но и сам сайт, и его CDN `cdn.trendhunterstatic.com` отдают 403 на любое обращение, кроме браузера** — curl, обычные загрузчики страниц и один из вспомогательных поисков не смогли получить ни одной страницы. Метод объявлен проприетарным. Отчёты, Horizon, Advisory — платные
- **Карточка:** [methodologies/trendhunter-score-tie.md](methodologies/trendhunter-score-tie.md)
- **Данные выгрузки:** [data/trendhunter_scores.csv](data/trendhunter_scores.csv) — 95 карточек: slug, балл, три показателя, доля мужчин, дата публикации. Проверка формулы встроена в `build_portal.py` и выполняется при каждой сборке портала; при расхождении хотя бы одного значения сборка останавливается
- **Что нашлось на странице методологии:** семь категорий сигналов; пять факторов Opportunity Score (Emergence, Stickiness, Institutional Commitment, Narrative, White Space) с определениями; фраза про свёртку («uses a weighted model where each lens plays a different role. Weighting can shift by category or industry»); три стадии Momentum / Durability / Saturation с наборами по четыре действия; FAQ из восьми вопросов, где названы горизонт (12–24 месяца) и отрасли, где модель сильнее всего (Food & Beverage и CPG)
- **Иллюстрации:** 5 в `assets/` (`th_*.png`) + уменьшенные `web_th_*.png` для портала. Механику несут две: `th_tie_hero.png` — **единственное место, где видна шкала Opportunity Score («7/10 Opportunity Score» на полукруглом индикаторе); в тексте страницы диапазон не назван ни разу**; `th_tie_three_stages.png` — три стадии оказались зонами одной непрерывной шкалы, значит численные границы существуют и не опубликованы. Ещё одна важна отрицательным результатом: `th_tie_five_factors.png` — полосы под пятью факторами одинаковой длины, то есть это оформление, а не шкалы
- **Арифметическая проверка: проведена и удалась полностью.** Выборка 1 — 45 карточек из шести категорий, на ней сформулирована гипотеза. Выборка 2 — 50 других карточек (подборка мегатренда Nostalgia + шесть других категорий, включая публикации до августа 2024 года), на ней гипотеза проверена без права подгонки. Итог: `Score = (Popularity + Activity + Freshness) / 3 / 10` с округлением до 0,1 — **совпало 95 из 95**. Отброшены: среднее двух (8 из 95), взвешенное 2:2:1 (20), взвешенное 1:1:2 (22), среднее геометрическое (43), медиана (16). Демография в балл не входит — иначе не сошлись бы наблюдения с распределением 10/90
- **Отдельно восстановлено:** Freshness — детерминированная функция времени публикации. Одна дата даёт одно значение (расхождения только ±1 п.п. внутри одного дня, то есть учитывается час), значение монотонно убывает, модель `100 · exp(−возраст_в_днях / 571)` совпала со всеми 66 датами при допуске ±1 п.п. Точная форма не доказана: линейная и логарифмическая отвергнуты, экспоненциальную и степенную на целых процентах не различить
- **Чего в источнике нет:** определений Popularity, Activity и Freshness — проверено восемь разделов сайта, слова встречаются только как подписи к полосам; определения слова «trend» / «idea» при том, что оба используются как термины; весов Opportunity Score; границ стадий; шкалы Opportunity Score в тексте (есть только на картинке); ни одного примера с частными оценками по пяти факторам; правила отбора идей в подборки «Top 100»
- **Числа масштаба платформы (страница /about-trend-hunter, 2026-08-09):** 3 580 995 713 просмотров за всё время · более 1 000 000 читателей в месяц · 409 473 участника сообщества · 1 100 брендов среди клиентов. **Счётчики живые:** за час значения изменились (409 473 против 409 537; просмотры 3 580 995 713 против 3 581 134 412), поэтому любую цифру масштаба надо приводить с датой
- **Замечание по методу разбора:** два вспомогательных поиска, работавших через сторонний текстовый прокси, сообщили, что связь паттернов с мегатрендами на сайте не указана и определений паттернов там нет. При чтении тех же страниц браузером и то и другое нашлось сразу и в явном виде: у каждого паттерна опубликовано определение и жёстко привязаны ровно три мегатренда, всего 18. Третий поиск не смог открыть ни одной страницы вообще. **Ещё одно подтверждение правила: пересказ годится только для навигации, разбор делается по первоисточнику.**
- **Доработка от 2026-08-09, вторая линия доказательств — архив Internet Archive.** Открывается браузером (инструментам поиска недоступен). Найдено: **до 2016 года Trend Hunter публиковал сырые данные под каждой идеей** — блок «Stats for <название>» с полями `Trending: Today & Viral`, `Traction: 1,884 clicks in 1 d` (на части страниц поле называется `Research:`), `Interest: 4 minutes`, `Concept:`, `Related: 48 examples / 37 photos`, `Segment: Males, 18-35`, `Comparison Set: 18 similar articles`. Снято 8 наблюдений старой системы, иллюстрация — `assets/th_archive_2016_stats.png`
- **Историческая стадийная шкала (сегодня отсутствует):** метка «Trending» двухсоставная — период (`Today`, `This Quarter`, `This Year`, `Older`) и «температура» (`Viral`, `Very Hot`, `Hot`, `Buzzing`, `Popular`). Прообраз нынешних Momentum / Durability / Saturation, но публиковался открыто. Полный перечень делений и правило присвоения не опубликованы; порядок температур восстановлен по величине балла как гипотеза
- **Когда прозрачность исчезла:** между копиями конца 2016 и 19 октября 2019. С 2019 года и по сегодняшний день рядом с баллом только «Score · Popularity · Activity · Freshness · VIEW MORE STATS», сырых данных нет
- **Кнопка «VIEW MORE STATS» проверена на живом сайте:** при нажатии в разметке не появляется ни одного нового показателя, наружу уходит единственный запрос — событие `view-more-stats` в Google Ads. Кнопка стоит с 2018 года
- **Формула проверена вторично, на архивных данных:** одна и та же идея в копиях 19.10.2019 / 26.10.2020 / 28.10.2021 / 31.05.2023 — Popularity 90 и Activity 95 неизменны, Freshness 14 → 11 → 9 → 8, балл 6,6 → 6,5 → 6,5 → 6,4. `(P+A+F)/3/10` сходится **4 из 4**. ### 6. Слабые сигналы по Yoon — карты KEM и KIM

- **Первоисточник (НЕ ЧИТАН, платный):** Yoon J., «Detecting weak signals for long-term business opportunities using text mining of Web news», Expert Systems with Applications 39(16), 2012, 12543–12550
- **Разобрано дословно по реализации:** Ebadi, Auger, Gauthier (National Research Council Canada + Defence R&D Canada), «Detecting emerging technologies and their evolution using deep learning and weak signal analysis», Journal of Informetrics — открытый препринт https://arxiv.org/pdf/2205.05449
- **Второй независимый источник формул:** Sustainability 12(19) 7848, https://www.mdpi.com/2071-1050/12/19/7848 — формулы DoV и DoD совпали дословно, включая `w = 0.05`
- **Дата обращения:** 2026-08-09 · **Карточка:** [methodologies/yoon-weak-signals-kem-kim.md](methodologies/yoon-weak-signals-kem-kim.md)
- **Иллюстрации:** 2 содержательные в `assets/` — `yoon_pipeline.png` (весь процесс: Scopus, 21 590 публикаций, 12 интервалов, 3 периода, топ-500 слов) и `yoon_hiltunen_cube.png` (рамка Hiltunen с осями Signal / Issue / Interpretation)
- **Что дала иллюстрация сверх текста:** границы трёх периодов (P1 с 1985–1987 по 1994–1996, P2 с 1997–1999 по 2006–2008, P3 с 2009–2011 по 2018–2020) — в тексте они не названы. Проверено пересчётом: разбиение сплошное, разрывов нет
- **Арифметическая проверка проведена на временном весе.** При `w = 0.05` множитель `(1 − w(n − j))` для самого старого интервала обнуляется при n = 21 и становится отрицательным при n = 22 — старые упоминания начинают уменьшать заметность слова. **Совпало 3 из 3** проверенных значений n. Дефект незаметен при трёхлетних интервалах кейса и фатален при месячной нарезке
- **Чего в источниках нет:** формула вертикальной оси карт знаками не приведена ни в одной из двух открытых работ — сказано только «the DoV's growth rate, calculated as the geometric mean». Открытого кода реализации не существует
- **Открытый вопрос:** принадлежит ли значение `w = 0.05` самому Yoon или подобрано цитирующими авторами. Разобранная работа пишет о нём как о собственном подборе («We set w = 0.05 as optimal after experimenting with different values»)

### 7. BERTrend — RTE France

- **Статья:** https://arxiv.org/abs/2411.05930 (Boutaleb, Picault, Grosjean, 2024) — открыта целиком
- **Код:** https://github.com/rte-france/BERTrend — MPL-2.0, 72 звезды, 672 коммита, Python ≥ 3.13, пакет `bertrend` на PyPI
- **Дата обращения и сверки с кодом:** 2026-08-09, ветка `main` · **Карточка:** [methodologies/bertrend-weak-signals.md](methodologies/bertrend-weak-signals.md)
- **Иллюстрации:** 2 содержательные в `assets/` — `bertrend_architecture.png` (схема конвейера с подписями «Median» и «10th centile» на вставке) и `bertrend_ui.png` (демонстратор с параметрами по умолчанию)
- **Главное, что дал разбор: сверка статьи с исполняемым кодом.** Прочитаны `bertrend/BERTrend.py`, `bertrend/trend_analysis/weak_signals.py` и `bertrend/config/bertrend_default_config.toml`. Три расхождения:
  1. **Верхний порог классификации назван по-разному в четырёх местах, тремя разными значениями:** 50-й процентиль в Algorithm 1 и «Median» на схеме (это одна величина под двумя именами), «Q3» в разделе 4.2, «90th percentile» в строке документации `BERTrend.py` — при фактическом `signal_classif_upper_bound = 75` в конфигурации. Нижний порог сходится везде: 10
  2. **Единица Δt в формуле затухания:** статья говорит «number of days», код считает `periods_since_last_update = time_diff // granularity`, то есть периоды. При granularity = 2 дня и квадрате в показателе затухание идёт вчетверо медленнее. За 20 дней молчания тема теряет 63% популярности по коду и 98% по буквальному тексту статьи
  3. **Окно проверки роста** в `_is_rising_popularity` зашито как `pd.Timedelta(days=14)`, хотя по статье должно управляться настраиваемым W
- **Подтверждённые кодом значения по умолчанию:** `decay_factor = 0.01`, `decay_power = 2`, `min_similarity = 0.7`, `granularity = 2`, `signal_classif_lower_bound = 10`, `signal_classif_upper_bound = 75`
- **Ещё одно мелкое расхождение:** порог zero-shot в статье назван 0,45, в интерфейсе демонстратора выставлен 0,40
- **Данные кейсов открыты:** arXiv cs.* — 367 248 аннотаций за 2017–2023; New York Times — 184 811 статей за 2019–2023
- **Вывод для метода разбора:** ни текст статьи, ни строка документации внутри кода не являются достаточным источником. Источник — конфигурация и тело функции

### Что из этого следует для разбора

Девять игроков с раскрытой механикой делятся на три непохожие группы:

1. **Платформы-конструкторы** (ITONICS, TrendOne, Futures Platform) — критерии настраиваемые, формула отдаётся пользователю. Та же болезнь, что у 4strat: механика есть, наполнения нет
2. **Отчёты с числами из данных** (McKinsey, iFORA) — показатели считаются автоматически из названных источников. **Это ровно то, чего не было ни в одном из семи разобранных**
3. **Двухосевые карты без свёртки** (Gartner Impact Radar, Forrester Tech Tide, Frost Radar) — сознательный отказ сводить оси в один балл


### Поиск от 2026-08-09 (второй заход): критерии из официальной статистики

Задача была поставлена иначе, чем в первом заходе: найти методологии, где числа берутся из **статистических данных о действиях** — цены, объёмы, доли, регистрации, торговые потоки, — а **не** из экспертных баллов и **не** из частоты упоминаний в текстах. Проверено четыре слоя: кривые обучения и прогноз по производственным рядам, системы опережающих индикаторов, большие статистические прогнозные системы, измерение диффузии по рыночным и административным данным.

**Главное отличие этого слоя от предыдущего.** Наукометрический слой (EScore, Yoon, BERTrend) меряет разговоры и весь целиком сводится к одной величине — скорости роста частоты упоминаний. Этот слой меряет действия, и единицы здесь **разные**: рубли и доллары за единицу продукции, процентные пункты доли, число регистраций, годы. Именно то, чего не хватало для второго независимого параметра.

#### S1. Закон Райта и кривые обучения — прогноз по ценам и объёмам производства

- **Nagy, Farmer, Bui, Trancik, «Statistical Basis for Predicting Technological Progress», PLoS ONE 8(2) e52669, 2013** — https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0052669 (полностью открыт)
  - Шесть конкурирующих моделей с дословными формулами: закон Мура `C(t) = C₀·e^(−bt)`; **закон Райта `C(Q) = C₀·Q^(−b)`**, где Q — кумулятивное производство; закон Годдарда `C(P) = C₀·P^(−b)`, где P — годовой выпуск; плюс три гибрида (Сахала, Нордхауса, Райт с лагом в год)
  - Данные: 62 технологии, 10–39 лет наблюдений на каждую, ряды «цена или себестоимость» и «объём производства». Открыты: Santa Fe Performance Curve Database, https://pcdb.santafe.edu
  - **Валидация есть и с числами:** ошибка хиндкастинга растёт линейно с горизонтом, типичный темп около 2,5% в год
- **Farmer & Lafond, «How predictable is technological progress?», Research Policy 45 (2016)** — https://arxiv.org/abs/1502.05274 (открытый препринт)
  - Даёт не только закон, но и **формулу распределения ошибки прогноза**: `Ξ(τ) = (m−1)/(m−3) × (τ + τ²/m)`, где τ — горизонт, m — длина ряда. Базовая модель — `y_t = y_(t−1) + μ + n_t`, где y = log(cost)
  - Валидация: 6391 хиндкаст на 53 технологиях; средняя автокорреляция θ ≈ 0,27
- **Way, Ives, Mealy, Farmer, «Empirically grounded technology forecasts and the energy transition», Joule 2022** — рабочая версия INET Oxford: https://oms-inet.files.svdcdn.com/staging/files/energy_transition_paper-INET-working-paper.pdf. Метод-предшественник с формулами открыт: https://arxiv.org/pdf/1703.05979. **Точные формулы версии 2022 не подтверждены** — cell.com отдаёт 403, PDF рабочей версии не распарсился
- **Практический смысл для нас:** даёт измеримый параметр силы тренда в **деньгах** — на сколько процентов падает стоимость при удвоении накопленного выпуска (learning rate `LR = 1 − 2^(−b)`). Единица не пересекается ни с частотой упоминаний, ни с долями

#### S2. INFORM Risk Index (JRC Еврокомиссии и OCHA ООН) — самый полный образец открытой свёртки на статистике

- Методология: https://drmkc.jrc.ec.europa.eu/inform-index/Portals/0/InfoRM/INFORM%20Concept%20and%20Methodology%20Version%202017%20Pdf%20FINAL.pdf (открыта целиком)
- **Формула итога:** `Risk = (Hazard & Exposure)^(1/3) × (Vulnerability)^(1/3) × (Lack of coping capacity)^(1/3)`, результат по шкале 0–10. Геометрическое среднее — то есть провал по одному измерению **нельзя** компенсировать другими, в отличие от арифметического среднего у SBS
- **Нормировка:** min-max с фиксированными, а не плавающими границами: `x_norm = (x − x_min)/(x_max − x_min) × 10`. Выбросы отсекаются по межквартильному размаху, критерий применимости — асимметрия < 2 и эксцесс < 3,5; для сильно скошенных распределений логарифмирование; при необходимости инверсия `x_inv = 10 − x_norm`
- **Веса опубликованы поимённо** по каждому уровню (например, внутри социально-экономической уязвимости: развитие и депривация 50%, неравенство 25%, зависимость от помощи 25%)
- **Пороги классов заданы числами и откалиброваны кластеризацией Уорда** по 191 стране за 5 лет: очень низкий 0,0–1,9, низкий 2,0–3,4, средний 3,5–4,9, высокий 5,0–6,4, очень высокий 6,5–10,0
- Входы: 54 показателя в версии 2017 (сейчас 74–80) — все из официальной статистики, с указанием единиц
- Данные открыты полностью, на всех уровнях модели: https://drmkc.jrc.ec.europa.eu/inform-index и data.humdata.org
- **Почему это важнее всего остального в очереди:** это ровно та конструкция, которую Катя собирается строить — многокритериальная оценка с нормировкой, весами, свёрткой и порогами, — но целиком на официальной статистике и с полностью опубликованным расчётом

#### S3. Системы опережающих индикаторов

- **OECD Composite Leading Indicators** — https://www.oecd.org/content/dam/oecd/en/data/methods/OECD-System-of-Composite-Leading-Indicators.pdf (открыт)
  - Полный конвейер обработки ряда: детрендирование фильтром Ходрика-Прескотта `min Σ(y_t − τ_t)² + λ Σ(τ_{t+1} − 2τ_t + τ_{t−1})²`, полосовой фильтр с отсечкой короче 12 и длиннее 120 месяцев; нормировка `x_norm = (x − среднее)/MAD + 100`, то есть неявный вес равен `1/MAD`; точки поворота по упрощённому алгоритму Bry-Boschan с минимальной фазой 5 месяцев и минимальным циклом 15 месяцев
  - Правило допуска: композит считается, только если доступно не менее 60% компонентов
  - Классификация опережения числами: опережающий — медианный лаг 2–8 месяцев, совпадающий — ±2 месяца
- **Conference Board Leading Economic Index** — https://www.conference-board.org/pdf_free/press/US%20LEI%20Technical%20Notes-April%202026.pdf
  - **Веса выводятся из данных, а не назначаются:** `w_x = 1/σ_x`, где σ — стандартное отклонение месячных изменений компонента, затем нормируются на сумму 1. Опубликованы поимённо: часы в промышленности 0,2464, ISM New Orders 0,1657, ожидания потребителей 0,1557, спред ставок 0,1200 и так далее
  - Правило сигнала «трёх Д» — глубина, длительность, диффузия: диффузионный индекс за 6 месяцев не выше 50% плюс порог по темпу. **Сам порог темпа плавающий**, разработчик его периодически пересчитывает, единого числа в источнике нет
  - Отдельно: заявление о «ни одного ложного сигнала с 1970 года» принадлежит самому разработчику, независимой проверки не найдено

#### S4. Измерение структурного сдвига и диффузии по данным о действиях

- **Shift-share analysis** — метод, не организация. Формула разложения: `e_i^(t+n) − e_i^t = NS_i + IM_i + RS_i`, где `NS = e_i^t × G` (общий рост), `IM = e_i^t × (G_i − G)` (отраслевой сдвиг), `RS = e_i^t × (g_i − G_i)` (конкурентный эффект). Применяется к любым официальным рядам занятости или торговли. Обзор: https://sites.temple.edu/yangyang/files/2014/08/SSA.pdf
- **RCA (индекс Балассы) и Economic Complexity Index** — Harvard Growth Lab
  - Формула RCA дословно: `RCA_cp = (X_cp / Σ_p X_cp) / (Σ_c X_cp / Σ_{c,p} X_cp)`, порог RCA > 1
  - **Открытый код:** https://github.com/cid-harvard/py-ecomplexity, лицензия MIT. Данные: UN Comtrade, бесплатно по ключу; Atlas of Economic Complexity — открытый датаверс Гарварда
- **Comin & Hobijn, «An Exploration of Technology Diffusion», AER 2010 + датасет CHAT** — https://www.nber.org/papers/w12314, данные https://www.nber.org/research/data/cross-country-historical-adoption-technology
  - Датасет открыт: более 100 технологий, более 150 стран, с 1800 года. Единица — **доля домохозяйств или страны, использующих технологию**, а не число статей о ней
  - Скорость диффузии моделируется логистической кривой с тремя параметрами. **Точная нотация оригинала не подтверждена** — PDF рабочей версии не распарсился, функциональная форма взята из независимых пересказов
- **Bass diffusion на реальных рядах продаж** — `f(t)/(1 − F(t)) = p + q·F(t)`, решение `F(t) = (1 − e^(−(p+q)t)) / (1 + (q/p)·e^(−(p+q)t))`, продажи `S(t) = m·f(t)`. Параметры p и q оцениваются регрессией по историческим продажам. Открытая реализация: pymc-marketing
- **US Census Bureau Business Formation Statistics** — https://www.census.gov/econ/bfs. Административные данные: заявки на регистрацию бизнеса (форма IRS SS-4), еженедельно с 2004 года, разрез по отраслям NAICS и штатам. Формулы нет — это счётный ряд, но ряд идеально «поведенческий»
- **Indeed Hiring Lab Job Postings Index** — https://github.com/hiring-lab/job_postings_tracker, лицензия CC BY 4.0. Индекс = процентное изменение сезонно сглаженного числа вакансий к базе 1 февраля 2020, скользящее среднее по 7 дням. **Пограничный случай:** сам факт публикации вакансии — действие, но навыки внутри вакансии извлекаются из текста

#### S5. Большие статистические прогнозные системы — источники готовых рядов, а не методологии оценки трендов

- **UN World Population Prospects** — https://population.un.org/wpp/. Байесовская иерархическая модель, **открытый код** в R-пакетах `bayesTFR`, `bayesLife`, `bayesPop`, `bayesMig` на CRAN. Неопределённость выражена вероятностными интервалами 80% и 95% по тысячам траекторий Монте-Карло. Горизонт до 2100
- **BLS Employment Projections** (США) — https://www.bls.gov/emp/documentation/projections-methods.htm. Методология открыта целиком, горизонт 10 лет, цепочка из шести моделей. **Неопределённость не выражена вообще** — точечный прогноз без интервалов
- **IHME Global Burden of Disease** — `DALY = YLL + YLD`, где `YLL = число смертей × стандартная ожидаемая продолжительность жизни`, `YLD = распространённость × вес нетрудоспособности`. Данные открыты по регистрации, код открыт **частично**; есть документированная критика закрытости — даже ВОЗ в 2010 не получила полного доступа к входным данным и коду
- **IEA World Energy Outlook** — формул нет в открытом доступе, неопределённость выражена сценариями, а не интервалами. Гибрид статистики энергобалансов и экспертных допущений по политике. Как методология не годится, как источник рядов — да
- **Росстат** — обследование бюджетов домашних хозяйств (около 47 800 домохозяйств, ежеквартально), обследование рабочей силы, ЕМИСС с машиночитаемой выгрузкой. Демографический прогноз до 2046 — **вариантный, сценарный, а не вероятностный**; методологический документ прямыми запросами не подтверждён, требует отдельной проверки

#### S6. Патентная аналитика — показатели, извлекающие из патента больше, чем счёт документов

Проверялось отдельно, потому что простой счёт патентов — это тот же счётчик документов, что и публикации, и в свою методологию его брать нельзя: он сольётся с частотой упоминаний. Нашлись показатели другого класса.

- **Поддержание патента в силе (Pakes, Schankerman)** — https://www.nber.org/system/files/working_papers/w5741/w5741.pdf (открыт). Правило дословно: владелец продлевает патент в возрасте `a` тогда и только тогда, когда `r₀ · exp(−δa) > cₐ`, где r₀ — начальная отдача, δ — годовая ставка обесценения, cₐ — пошлина за продление. **Это самый чистый поведенческий индикатор из всех найденных за оба захода:** владелец либо платит деньги, либо бросает патент. Никаких разговоров, никаких оценок. Данные открыты: реестры Роспатента (https://rospatent.gov.ru/opendata) и EPO Register
- **Generality и Originality (Trajtenberg, Henderson, Jaffe; формализовано в Hall, Jaffe, Trajtenberg, NBER WP 8498)** — https://www.nber.org/system/files/working_papers/w8498/w8498.pdf (открыт)
  - `Generality_i = 1 − Σ_k (s_ik)²`, где s_ik — доля цитирующих патент i патентов, относящихся к классу k
  - `Originality_i = 1 − Σ_k (s_ik)²`, где s_ik — доля цитируемых патентом i патентов из класса k
  - Это единица минус индекс Херфиндаля. Смысл: насколько широко изобретение расходится по областям или из скольких областей собрано
  - **Известное смещение:** при малом числе цитирований оба индекса систематически занижены (Hall, 2005, поправка вида `N/(N−1)`). Точную запись поправки подтвердить не удалось — PDF не распарсился
  - Готовая реализация: https://github.com/matt-wilder/patent-research (базовая версия, без поправки)
- **Technology Cycle Time** — медианный возраст патентов, процитированных на титульном листе. Единица — годы. Чем меньше, тем быстрее обновляется область. Формулы знаками нет, это описательная статистика. Источник концепции: CHI Research (Narin); проверка на сверхпроводниках — Kayal 1999, https://faculty.kfupm.edu.sa/mgm/akayal/Measuring%20Pace%20of%20Technological%20Progrss%20in%20IEEE%20ENG%20MGT.pdf
- **Patent family size** как мера ценности: в скольких юрисдикциях подана защита одного приоритета. Нормировка по когорте «технологическая область × год подачи» с обрезкой по 1-му и 99-му перцентилю — OECD STI Working Paper 2013/03, https://www.oecd.org/content/dam/oecd/en/publications/reports/2013/06/measuring-patent-quality_g17a22f5/5k4522wkw1r8-en.pdf
- **Forward citations и рыночная стоимость** — Hall, Jaffe, Trajtenberg, открытая версия NBER WP 7741: https://www.nber.org/system/files/working_papers/w7741/w7741.pdf. Единственный патентный показатель с опубликованной проверкой связи с деньгами (регрессия Tobin's Q). Точное уравнение из PDF извлечь не удалось
- **Логистическая кривая жизненного цикла по патентам:** `y = a / (1 + b·e^(−c·x))`, где y — кумулятивное число патентов к году x, a — насыщение, c — скорость роста. Пример открытой реализации: https://pmc.ncbi.nlm.nih.gov/articles/PMC9706162/
- **Открытые источники:** USPTO PatentsView — полностью бесплатно, API и bulk (https://patentsview.org); Google Patents Public Data на BigQuery — бесплатный датасет, платите только за объём запросов; EPO OPS — бесплатно с квотой; PATSTAT — платный, от 630 евро в год; Роспатент — открытые реестры
- **Важная оговорка про «экспертность»:** классы IPC и CPC проставляет патентный эксперт при экспертизе. То есть в generality, originality и radicalness экспертная разметка **уже встроена в данные** — но делать её самим не нужно, она бесплатно лежит в открытых базах

#### S7. Опросы населения — единственный слой, где свёртка опубликована полностью

Важное разграничение: опрос **населения** — это статистика поведения и установок, он годится. Опрос **экспертов** (Дельфи) не годится и в этот раздел не входит.

- **Business and Consumer Surveys Еврокомиссии** — https://economy-finance.ec.europa.eu/system/files/2023-02/bcs_user_guide.pdf (открыто)
  - **Формула баланса ответов** для пятибалльной шкалы: `B = (PP + ½P) − (½M + MM)`, где PP — «намного лучше», P — «лучше», M — «хуже», MM — «намного хуже». Единица — процентные пункты, диапазон от −100 до +100. **Это самая простая и самая переносимая формула свёртки из всех, встреченных за оба захода:** применима к любому опросному вопросу с порядковой шкалой
  - **Индикатор потребительской уверенности** (действует с января 2019): `CCI = (B(Q1) + B(Q2) + B(Q4) + B(Q9)) / 4` — среднее четырёх балансов: финансовое положение семьи за прошедший год, ожидания на год вперёд, ожидания по экономике страны, намерение делать крупные покупки. Веса равные, **выбраны экспертно, а не выведены из данных** — авторы это признают. Источник: https://economy-finance.ec.europa.eu/system/files/2022-12/new_cci_en.pdf
  - **Economic Sentiment Indicator:** веса секторов 40% промышленность, 30% услуги, 20% потребители, 5% розница, 5% строительство. Тоже назначены
  - Выборка: около 41 000 домохозяйств в месяц по ЕС. Данные машиночитаемы через Eurostat (`ei_bcs`), микроданные закрыты
- **Michigan Index of Consumer Sentiment** — https://data.sca.isr.umich.edu/fetchdoc.php?docid=24770 (открыто)
  - По каждому из пяти вопросов: `Relative Score = (% благоприятных − % неблагоприятных) + 100`
  - `ICS = Σ(пять Relative Score) / 6,7558 + 2,0`. База 1966 год = 100. Константа 2,0 — поправка на изменение дизайна выборки в 1950-е. Выборка около 500 интервью в месяц
- **OECD Consumer Confidence Index** — https://www.oecd.org/content/dam/oecd/en/data/methods/oecd-standardised-business-confidence-indicators-and-consumer-confidence-indicators.pdf. Четыре шага стандартизации: приведение периодичности, сглаживание MCD с окном до 5 месяцев, нормировка вычитанием среднего и делением на стандартное отклонение, амплитудная коррекция со сдвигом на +100. Порог 100 — долгосрочная норма
- **World Values Survey и European Values Study** — **микроданные полностью открыты и бесплатны** через GESIS: https://europeanvaluesstudy.eu/methodology-data-documentation/integrated-values-surveys/ (объединённый файл 1981–2022, 5 волн EVS плюс 7 волн WVS). Две оси Инглхарта-Вельцеля («традиционные против секулярно-рациональных», «выживание против самовыражения») строятся факторным анализом по 10 индикаторам, объясняющим более 70% межстрановой дисперсии. **Факторные нагрузки и формула свёртки в открытых источниках не найдены** — статья Inglehart & Welzel 2010 за пейволлом. Но раз микроданные открыты, индекс пересчитывается самостоятельно. Единственный источник, прямо предназначенный для измерения **сдвига ценностей во времени**
- **Открытые обследования расходов:** BLS Consumer Expenditure Survey — микроданные открыты полностью бесплатно (https://www.bls.gov/cex/pumd_data.htm), около 7000 интервью в квартал. Eurostat Household Budget Survey — раз в 5 лет, микроданные по запросу. Росстат ОБДХ — методология открыта, микроданные труднодоступны
- **Age-period-cohort анализ** — метод разложения опросных рядов на эффект возраста, периода и поколения. Требует длинных рядов, решает проблему линейной зависимости трёх факторов многоуровневыми моделями. Пояснение Pew: https://www.pewresearch.org/decoded/2023/05/22/assessing-the-effects-of-generation-using-age-period-cohort-analysis/

#### S8. Деньги и размер рынка — отрицательный результат, зафиксирован намеренно

**Открытой воспроизводимой методики оценки размера рынка и темпа его роста не существует.** Проверены Gartner, IDC, Statista, Grand View Research, MarketsandMarkets — все публикуют словесное описание процесса («сверху вниз плюс снизу вверх плюс триангуляция плюс экспертные интервью») и **ни одна не публикует формулу, веса, перечень первичных источников, сырые данные или код**. Независимой ретроспективной проверки прогнозов объёма рынка в академической литературе практически нет; единственная найденная содержательная проверка касается не размера рынка, а кривой хайпа (Steinert & Leifer, 2010) и подтверждает систематическое расхождение с фактом.

Практический вывод: **цифру вида «рынок вырастет до N миллиардов» в свою методологию брать нельзя** — она непроверяема по построению. Это закрывает целое направление и экономит время.

Что в денежном слое всё-таки годится:

- **OECD Frascati Manual** — https://www.oecd.org/content/dam/oecd/en/publications/reports/2017/10/frascati-manual-r-d-and-the-system-of-national-accounts_bdea4654/edb6e020-en.pdf. Единственный настоящий открытый международный стандарт. `Интенсивность НИОКР страны = GERD / ВВП`, `интенсивность отрасли = BERD отрасли / валовая добавленная стоимость отрасли`. Данные открыты через OECD.Stat и Eurostat. Ограничение: это макропоказатель по странам и секторам, а не по узкой теме
- **Гранты — единственный полностью открытый источник денег в разрезе тем.** CORDIS (проекты рамочных программ ЕС с суммами, CSV и XML, коммерческое использование разрешено), NSF Award Search API, NIH RePORTER API — всё бесплатно и машиночитаемо, с суммами, датами, ключевыми словами и организациями. **Готовой опубликованной формулы «сила тренда по грантам» не существует** — её придётся строить самим: сумма финансирования по теме за год, рост год к году, число разных организаций-получателей
- **CB Insights Mosaic Score** — https://www.cbinsights.com/mosaic-score. Редкий случай опубликованных весов: `Momentum 50% + Money 40% + Market 5% + Management 5%`, шкала 0–1000. Но это скоринг **компании**, а не тренда, и внутренность каждого компонента закрыта
- **NVCA / PitchBook Venture Monitor** — лучший бесплатный агрегированный источник венчурных денег: объём и число сделок по кварталам, стадиям и секторам. Только PDF, без API. Crunchbase закрыла бесплатный доступ к API в 2025 году

- **Формального бэктеста прогноза у IRENA** — публикуются наблюдённые постфактум learning rate, но проверки прогноза с числами ошибки нет

- **Открытой спецификации модели Business Cycle Clock (OECD/Eurostat)** — марковская модель переключения описана словами, формула живёт в отдельном «Handbook on Cyclical Composite Indicators», постранично получить не удалось. Это визуализация поверх непубличной параметрической модели
- **Единой формулы у Eurostat Euro-indicators** — это каталог рядов, а не свёртка

- **Открытых объёмов вакансий по навыкам у Lightcast** — таксономия навыков открыта, сами объёмы и скорость роста спроса платные
- **Опубликованной методологии оценки трендов на данных Numbeo** — не найдено ни одной
- **Открытой методики оценки размера рынка (TAM) и темпа роста (CAGR)** — не существует ни у одного из пяти проверенных игроков рынка (Gartner, IDC, Statista, Grand View Research, MarketsandMarkets). Публикуется только словесное описание процесса. **Это принципиальный отрицательный результат: рыночные цифры непроверяемы по построению, и брать их в методологию нельзя**
- **Независимой ретроспективной проверки прогнозов объёма рынка** — в академической литературе практически отсутствует. Единственная содержательная проверка касается кривой хайпа, а не рынка
- **Точной записи поправки Hall (2005) на смещение индексов generality и originality** — известно, что множитель имеет вид `N/(N−1)`, но дословно из PDF не извлечено
- **Уравнения регрессии Tobin's Q** из Hall, Jaffe, Trajtenberg — PDF не распарсился, символьная запись не подтверждена
- **Факторных нагрузок осей Инглхарта-Вельцеля** — статья 2010 года за пейволлом. Компенсируется тем, что микроданные World Values Survey открыты и индекс пересчитывается самостоятельно
- **Формулы агрегации у Nielsen, Kantar и GfK** — потребительские панели полностью коммерческие. Nielsen через Kilts Center — только для академических учреждений, от 3000 долларов
- **Бесплатного API Crunchbase** — закрыт в 2025 году, минимум 49 долларов в месяц
- **Методологического документа демографического прогноза Росстата** — найден факт публикации трёх сценариев, сама методика прямыми запросами не подтверждена

**Оговорка о границах.** O\*NET и ESCO проверены и **не подходят**: это экспертные таксономии профессий и навыков, а не измерители роста. Google и Apple Mobility Reports прекращены (апрель и октябрь 2022), исторические данные остались, но методологией оценки трендов они не были никогда.

### A. Обе стороны закрыты — разбирать первыми

**A1. Emergence Score (EScore)** — Porter, Garner, Carley, Newman
- Открытый полный текст: https://par.nsf.gov/servlets/purl/10076502 («Emergence Scoring to Identify Frontier R&D Topics and Key Players», Technological Forecasting and Social Change 146, 2019). Первоисточник метода — Carley, Newman, Porter, Garner, «An indicator of technical emergence», Scientometrics 115(1), 2018, https://link.springer.com/article/10.1007/s11192-018-2654-5 — **платный**, дословный текст оттуда не читан
- Формула дословно: `EScore = 2 × Active Period Trend + (Recent Trend + Mid-Year to Last Year Slope)`, все три слагаемых расписаны через отношение числа записей с термином к сумме корней из общего числа записей за соответствующие периоды
- Пороги числами: базовый период 3 года, активный 7 лет; термин обязан встретиться минимум в 3 годах и в 7 записях; отношение записей активного периода к базовому не ниже 2:1; термин не должен встречаться в 15% и более записей базового периода; авторов больше одного. Порог «высокого» EScore — 1.77 (√π, авторы прямо пишут, что число выбрано произвольно)
- Данные: Web of Science, MEDLINE, PatStat. MEDLINE бесплатна, остальные платные
- Код: **проприетарный** — скрипт Emergence Indicator внутри коммерческого VantagePoint. Открытой реализации нет
- Чем ценно: novelty, persistence и community **не входят в формулу числами** — они реализованы как пороги-фильтры до расчёта, а сам EScore меряет только рост. Это прямая критика из arXiv:2211.01348, https://arxiv.org/pdf/2211.01348

**A2. BERTrend** — RTE France, 2024
- arXiv: https://arxiv.org/abs/2411.05930, HTML-версия читается целиком
- Код открыт: https://github.com/rte-france/BERTrend, пакет PyPI `bertrend`
- Формула дословно: затухание популярности темы без обновлений `p_t^k = p_{t-1}^k · e^{-λΔt²}`, накопление `p_t'^k = p_{t-1}'^k + |D_t'^k|`
- Пороги: динамические процентили P10 / P50 в скользящем окне [t−W, t], три класса — noise / weak / strong
- Единственная находка, где формула, пороги и работающий код открыты одновременно

**A3. GitHub Innovation Graph + dg-uoi-analysis**
- Данные: https://github.com/github/innovationgraph — лицензия CC0, сырые CSV лежат прямо в репозитории, обновление ежеквартально с 2020
- Формула: `ln(dependents_at_t) − ln(dependents_at_release)` — лог-разница числа зависимых пакетов через 90/180 дней после релиза, со стратификацией по размеру пакета и типу релиза
- Статья: «Measuring Software Innovation with Open Source Software Development Data», https://arxiv.org/abs/2411.05087; код https://github.com/evamaxfield/dg-uoi-analysis (маленький, 2 звезды, но воспроизводимый)

### B. Формула открыта, данные платные или полуоткрытые

**B1. Yoon (2012), Degree of Visibility и Degree of Diffusion, карты KEM и KIM**
- Первоисточник платный: Expert Systems with Applications 39(16), 12543–12550
- Формулы восстановлены **дословно из двух независимых открытых источников**: `DoV_ij = (TF_ij / N_j) × (1 − w × (n − j))` и `DoD_ij = (DF_ij / N_j) × (1 − w × (n − j))`, константа времени `w = 0.05`. Источники: https://arxiv.org/pdf/2205.05449 и https://www.mdpi.com/2071-1050/12/19/7848
- Оси карт: KEM — X средняя частота термина, Y темп роста DoV (геометрическое среднее); KIM — X средняя частота документов, Y темп роста DoD. Деление квадрантов **по медианам**. Слабые сигналы — верхний левый квадрант: низкая частота, высокий рост
- Открытого кода реализации не найдено
- Развитие метода: WISDOM, https://arxiv.org/abs/2409.15340 — те же оси, но пороги не медиана, а среднее и ноль; корпус 9046 статей Scopus

**B2. Replicable Patent Indicators** — Abi Younes, de Rassenfosse
- https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4644778, рабочая версия https://cdm-repec.epfl.ch/iip-wpaper/WP24.pdf
- Код в виде SQL-запросов: https://kaggle.com/code/georgeabiyounes/replicable-patent-indicators
- Данные: Google Patents Public Data на BigQuery — бесплатно в пределах квоты, дальше платно и по ключу Google Cloud

**B3. OpenAlex + bibliometrix / openalexR**
- Данные полностью открыты (CC0), API бесплатный, 250+ млн работ: https://openalex.org
- Код открыт и живой: https://github.com/massimoaria/bibliometrix (MIT, 651 звезда), загрузка через https://github.com/ropensci/openalexR
- **Формула «трендовости» знаками не опубликована** — функции `fieldByYear`, `thematicEvolution`; надо смотреть исходники R-пакета. Это задача на разбор, а не готовый результат

### C. Свёртка открыта образцово, но это не про тренды

**C1. OECD/JRC «Handbook on Constructing Composite Indicators»**
- PDF: https://publications.jrc.ec.europa.eu/repository/handle/JRC47008, зеркало https://knowledge4policy.ec.europa.eu/sites/default/files/jrc47008_handbook_final.pdf
- Пять способов нормировки: z-score `(x−x̄)/σ`, min-max `(x−min)/(max−min)`, distance to reference, ranking, categorical scales по перцентилям
- Три семейства агрегации: линейная взвешенная сумма (полная компенсируемость), геометрическая взвешенное произведение (частичная), многокритериальная Кондорсе с матрицей превосходства `e_ij` = сумма весов показателей, по которым i превосходит j
- Числовой пример из источника: страна (21,1,1,1) даёт геометрическую свёртку 2.14, страна (6,6,6,6) даёт 6.00 — прямая демонстрация, чем геометрическая свёртка отличается от арифметической
- Это методология **свёртки вообще**, не оценки трендов. Забирать оттуда надо аппарат, а не критерии

**C2. Global Innovation Index (WIPO)** — образец применения C1
- https://www.wipo.int/web-publications/global-innovation-index-2025/en/appendix-i-conceptual-and-measurement-framework-of-the-global-innovation-index.html
- 78 показателей (63 hard data, 10 составных, 5 опросных), 7 столбцов, 21 подстолбец; нормировка min-max к 0–100; веса 0.5 или 1.0; порог мультиколлинеарности — корреляция выше 0.95
- Источник данных назван по каждому показателю, данные скачиваются: https://www.wipo.int/gii-ranking/en/

### D. Проверено и не подходит — фиксируем, чтобы не искать второй раз

Из механики опубликован один порог: «extreme growth» — рост кластера 8% и более в год на протяжении 3 лет. Расчёт закрыт, воспроизвести нельзя

- **Госфорсайт целиком** — формулы нет ни в одном источнике: UK Government Office for Science «Futures Toolkit» (https://assets.publishing.service.gov.uk/media/66c4493f057d859c0e8fa778/futures-toolkit-edition-2.pdf — проверено, числовых матриц и порогов нет), Policy Horizons Canada, Sitra Megatrends, UNDP Foresight Playbook, NATO EDT, Fraunhofer TechnologieRadar, JRC Megatrends Hub. ## Не нашлось

- Англоязычный первоисточник концепции «гравитационных трендов» — искали по формулировкам про массу, плотность и скорость трендов в стратегическом контексте; совпадения только из посторонних областей (трейдинговые индикаторы, гидрология, астрофизика).
- **Публичные клиентские радары на платформе 4strat** — ни одного. Проверялись: поисковые следы `powered by 4strat`, домены вида `*.trendradar.de`, структура URL `#/home-light/...`, подписи в подвале, упоминания названных клиентов (IKEA, Techniker Krankenkasse, Airbus, Audi, Европейская комиссия, EEA, НАТО, австрийские министерства, AIT). Платформа поддерживает встраивание дашбордов на внешний сайт — «interactive dashboards can be created and embedded on an external website», — но ни один такой дашборд не проиндексирован. Следствие: проверить набор критериев на чужом заполненном кейсе невозможно.
- **Численный порог детекции всплеска у 4strat** — правило названо («significant increases … compared to the average … of the last 15 days»), само значение `significant` не указано ни в справке, ни в настройках интерфейса.
- **Связь 4strat с Z_punkt, TrendOne или 4CAST** — искали, не подтвердилась. TrendOne имеет собственный отдельный продукт «Trend Radar & Relevance Scoring» — это конкурент, не связанный с 4strat, путать не надо.
- **«TSI methodology paper» компании Trendtracker** — упомянут в их же статье («as shown in the example chart on **page 3** of Trendtracker's TSI methodology paper»), но ссылки на него нет ни в статье, ни где-либо на сайте; в открытом доступе не найден. То есть публично методичка не существует, хотя вендор на неё ссылается.
- **Пороги ROESI** — правило перехода от Trend Strength и Trend Change к конкретной ступени не опубликовано ни на сайте, ни во внешних источниках.
- **Научная база Trendtracker** — публикаций основателей по обнаружению трендов или text mining не найдено; компании нет в официальном реестре спин-оффов Ghent University; патент, о котором пишет инвестор, в открытых патентных базах не обнаружен.
- **Определения Popularity, Activity и Freshness у Trend Hunter** — проверены восемь разделов сайта (`/about`, `/faq`, `/pro`, `/plans`, `/about-trend-hunter`, `/editorial-standards`, `/megatrends`, `/dashboard`). Слова встречаются исключительно как подписи к полосам на карточке идеи. FAQ посвящён правилам публикации для авторов, а не расшифровке метрик. **Дополнительно проверено в архиве:** FAQ 2016 года тоже не содержит ни слова о метриках — там только про портфолио авторов и продвижение в поиске. Отдельных страниц-объяснений (`/glossary`, `/methodology`, `/trend-score`, `/score`, `/stats`, `/help`, `/how-it-works`) не существует — все отдают 410 «Page Gone». Итог: **определения не публиковались никогда**, но сырые величины до 2016 года публиковались (см. пункт 4 в «Разобрано»).
- **Правило присвоения исторической метки «Trending»** — какие клики или какой возраст дают `Viral`, а какие `Buzzing`, не описано нигде. Порядок температур восстановлен по величине балла как гипотеза.
- **Содержимое закрытых разделов Trend Hunter** (`/pro-tools/*`, `/submit-new/*`, `/thcp/`, `/pdfView-pro/`, `/embed-templates/`) — снаружи не читается: 404, пустой редирект либо обрыв соединения. Именно там, судя по названиям, живут инструменты PRO-подписчиков и форма отправки идеи с критериями приёма.
- **Точная форма кривой свежести** — не доказана. Экспонента с характерным временем 571 день работает до ~2 лет возраста и ломается на 7-летнем (8 % факт против <1 % по модели). Линейная и логарифмическая отвергнуты; чтобы различить степенную и экспоненциальную с тяжёлым хвостом, нужна выборка с плотным покрытием возрастов от 2 до 10 лет — её я не собирал.
- **Веса и границы стадий Opportunity Score** — не опубликованы. Заявлено только, что модель взвешенная и что веса меняются по отрасли. Публичных примеров с частными оценками по пяти факторам нет ни одного, поэтому восстановить свёртку арифметикой не на чем — в отличие от публичного балла, который восстановился полностью.
- **Дословные авторские определения шести паттернов из книги «Better and Faster»** — в открытом вебе нет: Google Books не отдаёт текст этих страниц, полнотекстовой копии на archive.org нет, все найденные «определения» у сторонних сайтов честно помечены как пересказ. **Но это оказалось не нужно:** на самом сайте Trend Hunter у каждого паттерна опубликовано собственное определение, и в карточку взяты именно они.
- **Точный список «ловушек» Гутше** — расходится между книгами: в «Better and Faster» это три «farmer traps» (Complacency, Repetition, Protectiveness), в «Create the Future» — «7 traps of path dependency». Дословные формулировки не подтверждены по первоисточнику. К оценке трендов эта часть рамки отношения не имеет, поэтому в карточку не вошла.
- **Академические и независимые технические разборы методологии Trend Hunter** — не найдено ни одного: ни научных статей, ни диссертаций, ни разборов механики скоринга. Только промо-материалы самой компании и пересказы книг.
- **Валидация предсказательной силы Trend Hunter** — не заявлена и не найдена. Публикуются только показатели охвата (просмотры, число участников, число клиентов), но не точность оценок.
- **Независимые технические обзоры Trendtracker** — нет. G2 отдаёт только страницу альтернатив без отзывов, Gartner Peer Insights закрыт для чтения, Capterra содержит карточку без разбора механики.

### По поиску 2026-08-09

- **Воспроизводимая формула кривой хайпа** — не существует в открытом доступе. Проверены Dedehayir & Steinert «The hype cycle model: a review and future directions» (литобзор, формул нет), Jarvenpaa & Makinen, Steinert & Leifer «Scrutinizing Gartner's Hype Cycle Approach». Все академические попытки эмпирически поймать кривую используют простые заменители — счётчик статей в новостных базах как «видимость» и Google Trends как «интерес пользователей», — но формализованной формулы перехода между стадиями не даёт ни одна. Сам Gartner формулу не публикует. **Вывод: кривая хайпа непроверяема по построению, и это не трудность поиска, а свойство метода.**
- **Открытая реализация EScore** — нет. Скрипт живёт внутри платного VantagePoint; авторы пишут, что алгоритм в принципе не требует конкретного софта, но кода на Python или R не выложено.
- **Формула «Weakness» из El Akrouchi et al., «End-to-end LDA-based automatic weak signal detection in web news»** — статья платная (Knowledge-Based Systems 212, 106650), доступ заблокирован. Из вторичных пересказов известен только состав: coherence + closeness centrality + autocorrelation. Знаками формулу восстановить не удалось.
- **Оригинал Yoon (2012)** — платный, дословно не читан. Формулы DoV и DoD восстановлены по двум цитирующим открытым статьям; они совпали между собой, включая `w = 0.05`. Но **является ли 0.05 константой самого Yoon или подобранным значением цитирующих авторов — не проверено**, цитирующие статьи называют его то «оптимальным по экспериментам», то «экспертным выбором».
- **Формула трендовости в bibliometrix** — знаками не опубликована, надо читать исходники R-функции `fieldByYear`.
- **Единая воспроизводимая методика оценки трендов на GDELT** — не найдена. Датасет открыт, но устойчивой опубликованной методологии поверх него нет, только разовые исследования.

### Техническое ограничение разбора

В окружении **не установлен poppler**, из-за чего PDF не рендерятся и Read не может их прочитать: `pdftoppm is not installed`. Несколько ключевых первоисточников скачались как PDF и остались непрочитанными. Лечится одной командой `brew install poppler`. До этого разбор источников, живущих только в PDF, делать нельзя — правило скилла про обязательный просмотр иллюстраций не выполняется.
